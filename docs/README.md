# Evidencia para entrenamiento, nutricion y recuperacion

Coleccion curada de papers, revisiones sistematicas, metaanalisis y documentos de consenso para diseñar programas que combinen gimnasio, trote/carrera, crecimiento muscular, alimentacion y recuperacion.

## Alcance

- Adultos sanos y poblaciones recreativas, salvo que se indique otra cosa.
- Prioridad a revisiones sistematicas, metaanalisis y posicionamientos de organizaciones reconocidas.
- Las referencias enlazan a PubMed, DOI, revista o texto abierto. No se incluyen copias no autorizadas de articulos.
- Esta documentacion es educativa y no sustituye una evaluacion medica o la supervision de un profesional.

## Principios que aparecen con mayor consistencia

1. La progresion y la adherencia importan mas que una rutina "perfecta".
2. Para hipertrofia, distintos rangos de carga pueden funcionar si las series son suficientemente exigentes y el volumen es recuperable.
3. La carrera y la fuerza pueden coexistir. El riesgo de interferencia depende de volumen, intensidad, proximidad entre sesiones, modalidad y nivel de entrenamiento.
4. Cuando fuerza o hipertrofia son prioridad, conviene proteger la calidad de las sesiones de fuerza, separar sesiones exigentes cuando sea posible y controlar la fatiga de piernas.
5. Un paper aislado no debe convertirse en una regla universal: revisar poblacion, duracion, dosis, resultados y limitaciones.
6. Para sostener volumen de entrenamiento, la energia disponible, los carbohidratos, la proteina, la hidratacion y el sueño son parte del plan, no detalles secundarios.
7. Los suplementos tienen un papel secundario: primero deben estar cubiertos entrenamiento, alimentacion, salud y recuperacion.
